# Comisiones Aquaterra — instaladores

Aquí se publican los instaladores del programa **Comisiones Aquaterra**
(cálculo de comisiones de venta de Aquaterra Panamá). Este repositorio solo
contiene las versiones publicadas: no tiene código ni datos.

## Instalar

Descargue el último `ComisionesAquaterra-Setup-X.Y.Z.exe` desde
[Releases](../../releases/latest) y ejecútelo. No requiere permisos de
administrador.

## Actualizar

El programa avisa solo cuando hay una versión nueva («Actualizar ahora»).
